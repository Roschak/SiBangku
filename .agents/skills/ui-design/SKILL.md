# UI Design Skill

Build polished, modern, production-quality web interfaces.

## Design principles

- Use clean visual hierarchy.
- Use consistent spacing and typography.
- Prioritize responsive layouts.
- Design mobile-first.
- Avoid generic AI-looking layouts.
- Avoid excessive gradients.
- Avoid excessive rounded cards.
- Use subtle animations.
- Use meaningful hover and focus states.
- Use accessible semantic HTML.
- Prefer reusable components.
- Keep visual density balanced.
- Use Lucide icons when icons are needed.
- Prefer shadcn/ui components when the project uses them.
- Match the existing project's design system before introducing new styles.

## Before coding

1. Inspect the existing project.
2. Identify the framework and UI library.
3. Check existing components before creating duplicates.
4. Check current styling conventions.
5. Use Context7 for current library documentation when needed.

## UI quality checklist

- Desktop responsive
- Tablet responsive
- Mobile responsive
- Keyboard accessible
- Good contrast
- Consistent spacing
- Clear typography hierarchy
- Loading states
- Empty states
- Error states
- Hover/focus states
- No unnecessary visual clutter
